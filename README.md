# Cursos: Astronomía y Azure AZ-104

Web estática con dos cursos:

- **Astronomía y astrofísica** (español): 45 lecciones en seis fases, con ejercicios corregidos al momento.
- **Azure AZ-104** (inglés): 18 lecciones que siguen la guía oficial del examen, con laboratorios, 303 preguntas y un examen de práctica.

## Cómo usarla

Abre la web publicada con GitHub Pages (Settings, Pages, rama `main`, carpeta raíz), o descarga el repositorio y abre `index.html` en el navegador.

El progreso se guarda en el navegador de cada equipo (localStorage). El tutor y la sincronización entre dispositivos solo funcionan en la versión publicada en Claude.

## Archivos

- `index.html`: la aplicación.
- `lecciones.js`: curso de astronomía.
- `az104.js`: curso AZ-104.
- `fig-*.js`: figuras interactivas.
- `katex.min.css` y `fonts/`: fórmulas matemáticas.
